Что такое переменная?

Переменная - это контейнер для хранения данных. Можно представить ее как коробку с названием, в которой лежит какое-то значение.

Объявление переменных:

// let - можно изменять
let name = 'Иван';
let age = 25;

// const - нельзя изменять (константа)
const PI = 3.14;
const city = 'Москва';

// var - старый способ (не рекомендуется)
var oldVariable = 'старая переменная';

let - используй когда значение будет меняться

const - используй когда значение не меняется

var - устаревший способ, не используй

Типы данных:

1. String (строка) - текст

let name = 'Иван';
let message = "Привет!";
let text = `Меня зовут ${name}`; // шаблонная строка

2. Number (число)

let age = 25;
let price = 99.99;
let negative = -10;

3. Boolean (логический тип)

let isStudent = true;
let hasLicense = false;

4. Undefined (не определено)

let x;
console.log(x); // undefined

5. Null (пусто)

let user = null;

6. Array (массив)

let colors = ['red', 'green', 'blue'];
let numbers = [1, 2, 3, 4, 5];

7. Object (объект)

let person = {
    name: 'Иван',
    age: 25,
    city: 'Москва'
};

Изменение значения переменной:

let score = 0;
console.log(score); // 0

score = 10;
console.log(score); // 10

score = score + 5;
console.log(score); // 15
