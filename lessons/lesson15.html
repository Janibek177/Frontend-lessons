Что такое CSS Grid?

Grid - это двумерная система макетирования для создания сложных сеток.

Основы Grid

.container {
    display: grid;
    grid-template-columns: 200px 200px 200px;
    grid-template-rows: 100px 100px;
}

Единицы fr (fraction)

.container {
    display: grid;
    grid-template-columns: 1fr 2fr 1fr;
    /* 1 часть | 2 части | 1 часть */
}

repeat() - повторение

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    /* То же что: 1fr 1fr 1fr */
}

Gap - отступы между ячейками

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
    /* или раздельно: */
    row-gap: 20px;
    column-gap: 10px;
}

Размещение элементов

.item {
    grid-column: 1 / 3; /* занять колонки 1-2 */
    grid-row: 1 / 2;
}

/* Или короче: */
.item {
    grid-column: span 2; /* занять 2 колонки */
}

Grid Template Areas

.container {
    display: grid;
    grid-template-areas:
        "header header header"
        "sidebar content content"
        "footer footer footer";
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.content { grid-area: content; }
.footer { grid-area: footer; }

Auto-fit и minmax

.container {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
    /* Автоматическая адаптация! */
}

Выравнивание

.container {
    justify-items: center; /* по горизонтали */
    align-items: center; /* по вертикали */
}

/* Или для конкретного элемента: */
.item {
    justify-self: end;
    align-self: start;
}

Практическое задание:

1. Создайте галерею изображений 3x3 с помощью Grid

2. Создайте макет страницы: header, sidebar, content, footer

3. Используйте auto-fit для адаптивной сетки карточек
