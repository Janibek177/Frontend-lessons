Урок 4: Списки

Маркированные и нумерованные списки

← Назад к урокам

Маркированные списки (ul)

Используются для создания списков без нумерации.

<ul>
    <li>Первый пункт</li>
    <li>Второй пункт</li>
    <li>Третий пункт</li>
</ul>
  • Первый пункт
  • Второй пункт
  • Третий пункт

Нумерованные списки (ol)

Используются для создания пронумерованных списков.

<ol>
    <li>Шаг первый</li>
    <li>Шаг второй</li>
    <li>Шаг третий</li>
</ol>
  1. Шаг первый
  2. Шаг второй
  3. Шаг третий

Вложенные списки

Списки можно вкладывать друг в друга.

<ul>
    <li>Фрукты
        <ul>
            <li>Яблоко</li>
            <li>Банан</li>
        </ul>
    </li>
    <li>Овощи</li>
</ul>

Практическое задание:

1. Создайте список покупок (маркированный)

2. Создайте рецепт с шагами (нумерованный)

3. Сделайте вложенный список с категориями
