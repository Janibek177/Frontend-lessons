Transition - плавные переходы

.box {
    background: red;
    transition: all 0.3s ease;
}

.box:hover {
    background: blue;
    transform: scale(1.2);
}
Наведи на меня

Transform - трансформации

/* Поворот */
transform: rotate(45deg);

/* Масштаб */
transform: scale(1.5);

/* Смещение */
transform: translate(50px, 100px);

/* Наклон */
transform: skew(20deg);

/* Комбинация */
transform: rotate(45deg) scale(1.2);

Свойства transition

/* Полная форма */
transition-property: background;
transition-duration: 0.5s;
transition-timing-function: ease;
transition-delay: 0.2s;

/* Короткая форма */
transition: background 0.5s ease 0.2s;

/* Для всех свойств */
transition: all 0.3s;

Timing functions

ease - медленно-быстро-медленно (по умолчанию)

linear - равномерно

ease-in - медленный старт

ease-out - медленный финиш

ease-in-out - медленный старт и финиш

Animations - ключевые кадры

@keyframes slide {
    0% {
        transform: translateX(0);
    }
    100% {
        transform: translateX(200px);
    }
}

.box {
    animation: slide 2s ease infinite;
}

Свойства animation

animation-name: slide;
animation-duration: 2s;
animation-timing-function: ease;
animation-delay: 0s;
animation-iteration-count: infinite; /* или число */
animation-direction: alternate; /* normal, reverse, alternate */

/* Короткая форма */
animation: slide 2s ease 0s infinite alternate;

Пример вращения

@keyframes spin {
    from {
        transform: rotate(0deg);
    }
    to {
        transform: rotate(360deg);
    }
}

.spinner {
    animation: spin 2s linear infinite;
}

Сложная анимация

@keyframes bounce {
    0%, 100% {
        transform: translateY(0);
    }
    50% {
        transform: translateY(-50px);
    }
}
