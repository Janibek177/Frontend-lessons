Что такое Box Model?

Каждый элемент в HTML - это прямоугольная коробка, состоящая из 4 частей:

Content - содержимое (текст, изображения)

Padding - внутренний отступ (между контентом и границей)

Border - граница

Margin - внешний отступ (между элементами)

Padding (внутренний отступ)

div {
    padding: 20px; /* со всех сторон */
    padding: 10px 20px; /* вверх-низ | лево-право */
    padding: 10px 20px 30px 40px; /* верх | право | низ | лево */
}

/* Или отдельно */
padding-top: 10px;
padding-right: 20px;
padding-bottom: 10px;
padding-left: 20px;
Контент с padding 20px

Border (граница)

div {
    border: 2px solid #ff0000;
    border-width: 5px;
    border-style: solid; /* dashed, dotted, double */
    border-color: red;
    border-radius: 10px; /* скругление углов */
}

Margin (внешний отступ)

div {
    margin: 20px; /* со всех сторон */
    margin: 10px 20px; /* вверх-низ | лево-право */
    margin: 0 auto; /* центрирование блока */
}

margin-top: 10px;
margin-right: 20px;
margin-bottom: 10px;
margin-left: 20px;

Width и Height

div {
    width: 300px;
    height: 200px;
    max-width: 100%; /* максимальная ширина */
    min-height: 100px; /* минимальная высота */
}

Box-sizing

/* По умолчанию width не включает padding и border */
box-sizing: content-box;

/* Рекомендуется: width включает padding и border */
box-sizing: border-box;

/* Применить ко всем элементам */
* {
    box-sizing: border-box;
}

Практическое задание:

1. Создайте блок 300x200px с padding 20px и border 5px

2. Отцентрируйте блок с помощью margin: 0 auto

3. Добавьте border-radius для скругления углов

4. Примените box-sizing: border-box ко всем элементам
