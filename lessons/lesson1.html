Что такое HTML?

HTML (HyperText Markup Language) - это язык разметки гипертекста. Он используется для создания структуры веб-страниц. HTML не является языком программирования, это язык разметки, который определяет структуру вашего контента.

Базовая структура HTML документа

Каждый HTML документ имеет стандартную структуру:

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Моя первая страница</title>
</head>
<body>
    <h1>Привет, мир!</h1>
    <p>Это моя первая веб-страница.</p>
</body>
</html>

Объяснение структуры:

<!DOCTYPE html> - объявление типа документа. Говорит браузеру, что это HTML5 документ.

<html> - корневой элемент, содержит весь HTML код.

<head> - содержит метаинформацию о документе (не отображается на странице).

<meta charset="UTF-8"> - устанавливает кодировку документа.

<title> - заголовок страницы (отображается во вкладке браузера).

<body> - содержит весь видимый контент страницы.

Основные теги HTML:

<h1> - <h6> - заголовки (h1 - самый большой, h6 - самый маленький)

<p> - параграф текста

<br> - перенос строки

<hr> - горизонтальная линия

Практическое задание:

1. Создайте HTML файл с базовой структурой

2. Добавьте заголовок H1 с вашим именем

3. Добавьте параграф с описанием себя

4. Откройте файл в браузере
