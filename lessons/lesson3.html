Ссылки (тег <a>)

Ссылки позволяют создавать переходы между страницами.

<a href="https://google.com">Перейти в Google</a>
<a href="page2.html">Другая страница</a>
<a href="https://youtube.com" target="_blank">YouTube (новая вкладка)</a>

Атрибуты ссылок:

href - адрес страницы

target="_blank" - открыть в новой вкладке

title - всплывающая подсказка

Изображения (тег <img>)

Для вставки изображений используется тег <img>.

<img src="photo.jpg" alt="Описание фото">
<img src="logo.png" alt="Логотип" width="200" height="100">

Атрибуты изображений:

src - путь к файлу изображения

alt - альтернативный текст (важно для SEO и доступности)

width - ширина в пикселях

height - высота в пикселях

Практическое задание:

1. Создайте страницу со ссылками на ваши любимые сайты

2. Добавьте изображение (можно использовать URL из интернета)

3. Сделайте изображение кликабельным, обернув его в тег <a>
