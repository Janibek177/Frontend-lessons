Что такое адаптивный дизайн?

Адаптивный дизайн позволяет сайту выглядеть хорошо на любых устройствах: компьютере, планшете, телефоне.

Viewport meta tag

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Обязательно добавьте в head!

Media Queries

/* Для экранов меньше 768px */
@media (max-width: 768px) {
    .container {
        width: 100%;
        padding: 10px;
    }
}

Стандартные breakpoints

320px - мобильные телефоны

768px - планшеты

1024px - ноутбуки

1200px - десктопы

Mobile-first подход

/* Стили для мобильных (базовые) */
.container {
    width: 100%;
    padding: 10px;
}

/* Для планшетов и больше */
@media (min-width: 768px) {
    .container {
        width: 750px;
    }
}

/* Для десктопов */
@media (min-width: 1200px) {
    .container {
        width: 1140px;
    }
}

Адаптивные изображения

img {
    max-width: 100%;
    height: auto;
}

Адаптивные сетки с Flexbox

.grid {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;
}

.item {
    flex: 1 1 300px;
}

Адаптивные сетки с Grid

.grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
    gap: 20px;
}

Скрытие элементов

/* Скрыть на мобильных */
@media (max-width: 768px) {
    .desktop-only {
        display: none;
    }
}

/* Показать только на мобильных */
.mobile-only {
    display: block;
}

@media (min-width: 769px) {
    .mobile-only {
        display: none;
    }
}

Адаптивные шрифты

h1 {
    font-size: 2rem;
}

@media (min-width: 768px) {
    h1 {
        font-size: 3rem;
    }
}

/* Или с clamp() */
h1 {
    font-size: clamp(2rem, 5vw, 4rem);
}

Ориентация экрана

@media (orientation: portrait) {
    /* Вертикальная ориентация */
}

@media (orientation: landscape) {
    /* Горизонтальная ориентация */
}

Практическое задание:

1. Создайте страницу с адаптивной сеткой из 3 колонок (на мобильном 1 колонка)

2. Добавьте адаптивное меню (гамбургер на мобильных)

3. Измените размер шрифтов для разных экранов

4. Скройте боковую панель на мобильных
