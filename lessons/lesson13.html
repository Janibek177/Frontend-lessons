Display

Свойство display определяет как элемент отображается на странице.

display: block

div {
    display: block;
}

• Занимает всю ширину родителя

• Начинается с новой строки

• Можно задать width и height

Примеры: div, p, h1, section

display: inline

span {
    display: inline;
}

• Занимает только необходимую ширину

• Не переносится на новую строку

• НЕ работают width и height

Примеры: span, a, strong

display: inline-block

button {
    display: inline-block;
}

• Элементы в строке, но с width и height

• Лучшее из обоих миров

Block 2

display: none

div {
    display: none; /* полностью скрывает элемент */
}

Position

Свойство position управляет позиционированием элемента.

position: static (по умолчанию)

div {
    position: static;
}

Обычное положение в потоке документа

position: relative

div {
    position: relative;
    top: 20px;
    left: 30px;
}

Смещается относительно своего обычного положения

position: absolute

div {
    position: absolute;
    top: 0;
    right: 0;
}

Позиционируется относительно ближайшего positioned родителя

position: fixed

header {
    position: fixed;
    top: 0;
    width: 100%;
}

Фиксируется относительно окна браузера (не прокручивается)

position: sticky

nav {
    position: sticky;
    top: 0;
}

Ведет себя как relative, но становится fixed при прокрутке

Z-index (слои)

div {
    position: absolute;
    z-index: 10; /* чем больше, тем выше слой */
}

Практическое задание:

1. Создайте fixed header, который остается вверху при прокрутке

2. Создайте кнопку с position: absolute в правом нижнем углу

3. Поэкспериментируйте с z-index на перекрывающихся элементах
