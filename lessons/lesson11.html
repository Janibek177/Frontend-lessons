Урок 11: Шрифты и текст

Стилизация текста в CSS

← Назад к урокам

Font-family (семейство шрифтов)

p {
    font-family: Arial, sans-serif;
    font-family: 'Times New Roman', serif;
    font-family: 'Courier New', monospace;
}

Font-size (размер шрифта)

h1 { font-size: 32px; }
p { font-size: 16px; }
span { font-size: 1.5em; } /* относительный размер */
Маленький текст (12px)
Средний текст (18px)
Большой текст (24px)

Font-weight (жирность)

p { font-weight: normal; } /* 400 */
strong { font-weight: bold; } /* 700 */
h1 { font-weight: 900; }
Тонкий текст (300)
Жирный текст (700)

Text-align (выравнивание)

text-align: left; /* по левому краю */
text-align: center; /* по центру */
text-align: right; /* по правому краю */
text-align: justify; /* по ширине */
Текст слева
Текст по центру
Текст справа

Text-decoration (оформление)

text-decoration: none; /* без оформления */
text-decoration: underline; /* подчеркнутый */
text-decoration: line-through; /* зачеркнутый */

Line-height (межстрочный интервал)

p {
    line-height: 1.5; /* в 1.5 раза больше размера шрифта */
    line-height: 24px;
}

Letter-spacing (расстояние между буквами)

h1 {
    letter-spacing: 2px;
}
Р А З Р Е Ж Е Н Н Ы Й

Text-transform

text-transform: uppercase; /* ВСЕ ЗАГЛАВНЫЕ */
text-transform: lowercase; /* все строчные */
text-transform: capitalize; /* Первая Буква Заглавная */

Практическое задание:

1. Создайте заголовок красным шрифтом, размером 36px, выровненный по центру

2. Создайте параграф с line-height: 1.8 и letter-spacing: 1px

3. Поэкспериментируйте с разными шрифтами
