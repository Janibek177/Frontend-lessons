Что такое JavaScript?

JavaScript - это язык программирования, который делает веб-страницы интерактивными. С его помощью можно создавать игры, анимации, обрабатывать формы и многое другое.

Подключение JavaScript:

1. Внутри HTML (между тегами script):

<script>
    console.log('Привет, мир!');
</script>

2. Внешний файл (рекомендуется):

<script src="script.js"></script>

Консоль разработчика:

Нажмите F12 в браузере, чтобы открыть консоль и увидеть вывод JavaScript.

Console.log - вывод в консоль:

console.log('Привет!');
console.log(100);
console.log('Результат:', 5 + 5);

Комментарии:

// Однострочный комментарий

/*
  Многострочный
  комментарий
*/

Точка с запятой:

В JavaScript рекомендуется ставить точку с запятой в конце каждой команды.

console.log('Первая строка');
console.log('Вторая строка');

Первая программа:

// Выводим приветствие
console.log('Привет, мир!');
console.log('Я изучаю JavaScript!');

// Простые вычисления
console.log(10 + 5);
console.log(20 * 3);

Практическое задание:

1. Создайте HTML файл и подключите JS файл

2. Выведите в консоль "Привет, мое имя [ваше имя]"

3. Выведите результат нескольких математических операций

4. Добавьте комментарии к своему коду
