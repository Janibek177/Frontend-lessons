Урок 10: Цвета и фон

Работа с цветами и фоновыми изображениями

← Назад к урокам

Способы указания цвета:

/* Название цвета */
color: red;
color: blue;

/* HEX код */
color: #ff0000;
color: #000000;

/* RGB */
color: rgb(255, 0, 0);

/* RGBA (с прозрачностью) */
color: rgba(255, 0, 0, 0.5);

Цвет текста и фона:

p {
    color: white;
    background-color: #000000;
}
Красный фон, черный текст
Черный фон, зеленый текст

Фоновые изображения:

div {
    background-image: url('image.jpg');
    background-size: cover;
    background-position: center;
    background-repeat: no-repeat;
}

Градиенты:

/* Линейный градиент */
background: linear-gradient(to right, red, black);

/* Радиальный градиент */
background: radial-gradient(circle, red, black);
Градиент от красного к черному

Практическое задание:

1. Создайте блок с черным фоном и красным текстом

2. Создайте градиентный фон для header

3. Поэкспериментируйте с разными цветами в формате HEX и RGB
