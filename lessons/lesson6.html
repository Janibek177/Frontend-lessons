Основы форм

Формы используются для сбора данных от пользователей.

<form>
    <label>Имя:</label>
    <input type="text" name="name">
    <button type="submit">Отправить</button>
</form>

Типы полей ввода

text - текстовое поле

password - поле для пароля

email - поле для email

number - числовое поле

checkbox - чекбокс

radio - радиокнопка

file - загрузка файла

date - выбор даты
