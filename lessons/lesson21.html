Что такое условия?

Условия позволяют выполнять разный код в зависимости от ситуации.

Оператор if (если):

let age = 18;

if (age >= 18) {
    console.log('Вы взрослый');
}

if...else (если...иначе):

let age = 15;

if (age >= 18) {
    console.log('Вы взрослый');
} else {
    console.log('Вы несовершеннолетний');
}

else if (множественные условия):

let score = 85;

if (score >= 90) {
    console.log('Отлично!');
} else if (score >= 70) {
    console.log('Хорошо!');
} else if (score >= 50) {
    console.log('Удовлетворительно');
} else {
    console.log('Плохо');
}

Операторы сравнения:

== - равно (не строгое)

=== - равно (строгое, рекомендуется)

!= - не равно

!== - не равно (строгое)

> - больше

< - меньше

>= - больше или равно

<= - меньше или равно

Логические операторы:

// && (И) - оба условия должны быть true
if (age >= 18 && hasLicense) {
    console.log('Можете водить');
}

// || (ИЛИ) - хотя бы одно условие true
if (day === 'Saturday' || day === 'Sunday') {
    console.log('Выходной!');
}

// ! (НЕ) - инверсия
if (!isRaining) {
    console.log('Можно гулять');
}

Тернарный оператор (краткая форма):

let age = 20;
let status = age >= 18 ? 'взрослый' : 'ребенок';
console.log(status); // 'взрослый'

Switch (множественный выбор):

let day = 'Monday';

switch (day) {
    case 'Monday':
        console.log('Понедельник');
        break;
    case 'Friday':
        console.log('Пятница!');
        break;
    default:
        console.log('Обычный день');
}

Практическое задание:

1. Создайте переменную с температурой и выведите "Жарко", "Тепло" или "Холодно"

2. Проверьте четное ли число (подсказка: используйте оператор %)

3. Создайте простой калькулятор с switch для операций +, -, *, /
