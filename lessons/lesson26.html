Что такое DOM?

DOM (Document Object Model) - это представление HTML страницы в виде дерева объектов, которыми можно управлять через JavaScript.

Поиск элементов:

// По ID
let element = document.getElementById('myId');

// По классу (первый найденный)
let element = document.querySelector('.myClass');

// Все элементы с классом
let elements = document.querySelectorAll('.myClass');

// По тегу
let paragraphs = document.querySelectorAll('p');

Изменение содержимого:

// Изменить текст
element.textContent = 'Новый текст';

// Изменить HTML внутри элемента
element.innerHTML = '<strong>Жирный текст</strong>';

Изменение стилей:

element.style.color = 'red';
element.style.backgroundColor = 'black';
element.style.fontSize = '20px';
element.style.display = 'none'; // скрыть

Работа с классами:

// Добавить класс
element.classList.add('active');

// Удалить класс
element.classList.remove('active');

// Переключить класс
element.classList.toggle('active');

// Проверить наличие класса
if (element.classList.contains('active')) {
    console.log('Класс есть');
}

Создание новых элементов:

// Создать элемент
let newDiv = document.createElement('div');
newDiv.textContent = 'Новый блок';
newDiv.className = 'my-class';

// Добавить в конец родителя
document.body.appendChild(newDiv);

// Добавить перед элементом
parent.insertBefore(newDiv, existingElement);

Удаление элементов:

element.remove();

Получение и изменение атрибутов:

// Получить атрибут
let src = img.getAttribute('src');

// Установить атрибут
img.setAttribute('src', 'new-image.jpg');

// Удалить атрибут
img.removeAttribute('alt');
