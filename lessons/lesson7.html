Что такое семантика?

Семантические теги описывают смысл содержимого, а не просто его внешний вид. Это важно для SEO и доступности.

Основные семантические теги:

<header> - шапка сайта или раздела

<nav> - навигационное меню

<main> - основное содержимое страницы

<section> - раздел контента

<article> - независимая статья

<aside> - боковая панель

<footer> - подвал сайта

Пример структуры:

<header>
    <h1>Мой сайт</h1>
    <nav>
        <a href="#">Главная</a>
        <a href="#">О нас</a>
    </nav>
</header>

<main>
    <section>
        <h2>Новости</h2>
        <article>
            <h3>Заголовок статьи</h3>
            <p>Текст статьи...</p>
        </article>
    </section>
</main>

<footer>
    <p>© 2026 Мой сайт</p>
</footer>

Почему это важно?

✓ Улучшает SEO (поисковая оптимизация)

✓ Делает код понятнее

✓ Помогает скринридерам для людей с ограничениями

✓ Облегчает поддержку кода

Практическое задание:

1. Создайте страницу блога с правильной семантической структурой

2. Используйте header, nav, main, article, footer

3. Добавьте несколько статей внутри main
