Что такое Flexbox?

Flexbox - это мощная система макетирования, которая упрощает выравнивание и распределение элементов.

Основы Flexbox:

.container {
    display: flex;
}

2
3

Основные свойства контейнера:

flex-direction - направление (row, column)

justify-content - выравнивание по главной оси

align-items - выравнивание по поперечной оси

gap - отступы между элементами

flex-wrap - перенос элементов

justify-content (горизонтальное выравнивание):

justify-content: flex-start; /* в начало */
justify-content: center; /* по центру */
justify-content: flex-end; /* в конец */
justify-content: space-between; /* с отступами */
justify-content: space-around; /* вокруг элементов */

align-items (вертикальное выравнивание):

align-items: flex-start; /* вверх */
align-items: center; /* по центру */
align-items: flex-end; /* вниз */
align-items: stretch; /* растянуть */

flex-direction:

flex-direction: row; /* горизонтально */
flex-direction: column; /* вертикально */
