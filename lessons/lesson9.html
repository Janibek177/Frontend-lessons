Урок 9: Селекторы CSS

Как выбирать элементы для стилизации

← Назад к урокам

Типы селекторов:

1. Селектор по тегу

p {
    color: white;
}

Выбирает все элементы <p>

2. Селектор по классу

.my-class {
    color: red;
}

<div class="my-class">Текст</div>

Выбирает элементы с классом "my-class"

3. Селектор по ID

#my-id {
    color: blue;
}

<div id="my-id">Текст</div>

Выбирает элемент с ID "my-id"

4. Универсальный селектор

* {
    margin: 0;
    padding: 0;
}

Выбирает ВСЕ элементы на странице

5. Комбинированные селекторы

/* Несколько селекторов */
h1, h2, h3 {
    color: red;
}

/* Вложенность */
div p {
    color: blue;
}

/* Прямой потомок */
div > p {
    color: green;
}

Приоритет селекторов:

1. Inline styles - самый высокий приоритет

2. ID (#my-id)

3. Классы (.my-class)

4. Теги (p, div, h1)

Практическое задание:

1. Создайте 3 параграфа с разными классами

2. Стилизуйте каждый класс своим цветом

3. Создайте элемент с ID и сделайте его больше остальных
