Что такое CSS?

CSS (Cascading Style Sheets) - это язык стилей, который описывает внешний вид HTML элементов. С помощью CSS можно изменять цвета, шрифты, размеры, расположение элементов и многое другое.

Три способа подключения CSS:

1. Inline CSS (в строке)

<h1 style="color: red; font-size: 24px;">Заголовок</h1>

2. Internal CSS (внутренний)

<head>
    <style>
        h1 {
            color: red;
            font-size: 24px;
        }
    </style>
</head>

3. External CSS (внешний) - Рекомендуется!

<head>
    <link rel="stylesheet" href="style.css">
</head>

Синтаксис CSS:

селектор {
    свойство: значение;
    другое-свойство: другое-значение;
}

Пример:

h1 {
    color: #ff0000;
    font-size: 32px;
    text-align: center;
}

h1 - селектор (выбирает элемент)

color - свойство

#ff0000 - значение (красный цвет)

Практическое задание:

1. Создайте HTML файл и внешний CSS файл

2. Подключите CSS к HTML через тег link

3. Измените цвет заголовка на красный

4. Измените цвет фона страницы на черный
